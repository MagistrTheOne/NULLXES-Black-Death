1. Dry-fit spars + ribs → bond  
2. Install battery tray / payload floor (Nomex)  
3. Route HV + dual DC-DC per `04_propulsion_energy/power_distribution/ALPHA_5x5_PDB.md`  
4. Mount motors/ESCs; fold props clear of TE  
5. Install FC (L0) + compute A/B + sensors (camera FOVs per requirements)  
6. Elevon hinges on rear spar; mass-balance per flutter screen  
7. Close remaining skins / access panels  
8. Functional: dual heartbeat, L0 hold, thrust spool  
9. Weigh & CG check (CG target: near MAC quarter-chord — refine after XFLR5)  
10. Sign-off traveler → flight test card
