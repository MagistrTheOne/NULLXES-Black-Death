# ALPHA 5×5 — Build order

1. Cut foam cores / Nomex panels per loft from `02_aerodynamics/geometry` + blended sections  
2. Layup spar caps/webs (`09_manufacturing/composites/ALPHA_5x5_LAYUP.md`)  
3. Bond ribs at `spar_rib_layout.yaml` stations  
4. Close skins (wing halves → join at center carry-through)  
5. Install LG hardpoints on front spar  
6. Avionics bench bring-up (A/B + L0) on ground jig — `08_prototypes/avionics_benches/`  
7. Motor/ESC static thrust test ≥226 N sum  
8. Integration weigh-in vs mass rev A (42 kg)  
9. Taxi → CTOL flight-1 (payload 0)
